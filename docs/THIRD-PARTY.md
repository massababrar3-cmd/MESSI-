# Third-party software

MESSI's application code and UI were independently written for this repository. No SPRY code, assets, private interfaces or training content are included.

The dependency locks and DEPENDENCY-INVENTORY.json record the packages used for this build. Their upstream notices/licence files remain authoritative. React, Three.js, FastAPI, SQLAlchemy and other components retain their original licences; do not describe the whole product as having one permissive dependency licence. In particular, review psycopg and its bundled binary/library distribution obligations before distributing images commercially. Docker base images and PostgreSQL have their own component inventories and notices.

A distribution licence for the original MESSI application has not been selected by this implementation task. The owner should choose one and review third-party obligations before redistribution. No proprietary geological-format SDK or commercial solver is bundled.
